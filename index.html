Purity and Entropy Explorer

Entropy measures how impure (mixed) a group is. A group where everyone is in the same class is pure and has entropy 0. A 50/50 group is the most mixed and has entropy 1 bit.

H(X) = − Σ p(x) · log₂ p(x)

Entropy curve

Step-by-step

Pure group (H = 0)

Everyone is in one class. We know the answer for sure, so there is no uncertainty. These are the two ends of the curve.

Most impure (H = 1)

Half are in each class. A random pick is a coin toss, so uncertainty is highest. This is the top of the curve.

Why 0 · log₂ 0 = 0

log₂ 0 is undefined, but p · log₂ p gets closer and closer to 0 as p shrinks. So a class with no members adds nothing.
